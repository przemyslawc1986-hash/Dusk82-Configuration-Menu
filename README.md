# Dusk82-Configuration-Menu
[h1]Dusk '82 - Advanced In-Game Configuration Menu (F1)[/h1]

A lightweight and essential BepInEx mod for [b]Dusk '82[/b] that adds a clean, in-game configuration overlay. Easily manage window modes, change resolutions on the fly, and tweak audio settings without restarting the game!

[h2]✨ Key Features[/h2]
[list]
[*][b]F1 Menu Toggle:[/b] Press [b]F1[/b] at any time during gameplay to instantly open or close the configuration overlay.
[*][b]Resolution Manager:[/b] Scroll through and select any available monitor resolution instantly.
[*][b]Display Modes:[/b] Seamlessly switch between Windowed and Fullscreen modes.
[*][b]Audio Controls:[/b] Quick mute/unmute button and an adjustable master volume slider.
[*][b]Multi-Language Support (12 Languages):[/b] Fully localized interface supporting [b]EN, PL, DE, UA, FR, CZ, SK, CN, ES, PT, JA, RU[/b] with a one-click toggle directly inside the menu!
[*][b]Smart Cursor Management:[/b] Automatically unlocks and locks the mouse cursor when opening and closing the menu.
[/list]

[h2]📥 Installation Instructions[/h2]
[list]
[*]Make sure you have [b]BepInEx[/b] installed for [i]Dusk '82[/i] (x64 version).
[*]Download and place the [b]Dusk82Patch.dll[/b] file into your game's plugins directory:
[code].../Steam/steamapps/common/Dusk '82/BepInEx/plugins/[/code]
[*]Launch the game, press [b]F1[/b], and enjoy!
[/list]
