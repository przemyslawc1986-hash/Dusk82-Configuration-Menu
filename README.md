Dusk '82 - Advanced In-Game Configuration Menu (F1)

A lightweight and essential BepInEx mod for Dusk '82 that adds a clean, in-game configuration overlay. Easily manage window modes, change resolutions on the fly, and tweak audio settings without restarting the game!

Key Features:

F1 Menu Toggle: Press F1 at any time during gameplay to instantly open or close the configuration overlay.

Resolution Manager: Scroll through and select any available monitor resolution instantly.

Display Modes: Seamlessly switch between Windowed and Fullscreen modes.

Audio Controls: Quick mute/unmute button and an adjustable master volume slider.

Multi-Language Support (12 Languages): Fully localized interface supporting EN, PL, DE, UA, FR, CZ, SK, CN, ES, PT, JA, RU with a one-click toggle directly inside the menu!

Smart Cursor Management: Automatically unlocks and locks the mouse cursor when opening and closing the menu.

Installation Instructions:

Make sure you have BepInEx installed for Dusk '82 (x64 version).

Download and place the Dusk82Patch.dll file into your game's plugins directory:
.../Steam/steamapps/common/Dusk '82/BepInEx/plugins/

Launch the game, press F1, and enjoy!
